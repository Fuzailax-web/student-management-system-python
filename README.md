# 🎓 Student Management System

A Python-based Student Management System built using Object-Oriented Programming (OOP). The application allows users to manage student records through CRUD (Create, Read, Update, Delete) operations with persistent JSON storage.

---

## 📌 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student by ID
- ✏️ Update Student Details
- 🗑️ Delete Student
- 💾 Persistent JSON Storage
- ⚠️ Exception Handling
- 🏗️ Modular Code Structure
- 🐍 Built with Python

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Fuzailax-web/student-management-system-python.git
```

Go to the project folder:

```bash
cd student-management-system-python
```

Run the project:

```bash
python3 main.py
```
